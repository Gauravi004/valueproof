\# P4 - Location Intelligence



\## Purpose



The Location Intelligence module provides location-based features that can be used by the property valuation engine.



\## Input



The system takes a property's:



\- property\_id

\- latitude

\- longitude



Example:



```json

{

&#x20;   "property\_id": "P001",

&#x20;   "latitude": 30.12,

&#x20;   "longitude": 76.46

}
